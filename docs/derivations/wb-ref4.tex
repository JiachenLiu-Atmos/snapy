\section*{289: a fourth-order x1 well-balanced face density (\texttt{SNAP\_WB\_REF4})}

This file derives the switch \texttt{SNAP\_WB\_REF4} (off unless set, read once per process) step by step and states
the oracle it is tested against. The method is the face part of Jiheng's specification \texttt{wbref\_exact\_spec.md}
(taken from his derivation at c5b810d, which was not
available on any GitHub fork when this was written). The exact weights and identities used below are checked
by \texttt{docs/derivations/wb\_ref4\_weights.py} (sympy). The code is \texttt{src/hydro/wb\_ref4.cpp}, called from
\texttt{HydroImpl::\_hydro\_ref\_x1} (\texttt{src/hydro/hydro.cpp}).

Scope: Cartesian-exact. On spherical-polar and cubed-sphere grids the same index-space operators are applied
unchanged, which is not $r^2$-measure exact; that extension is a separate change.

\section*{0. Notation}

\begin{itemize}
\item $z \equiv x_1$, gravity $g$ downward. Cell $i$ spans $[z_{i-1/2}, z_{i+1/2}]$ with width $\Delta z_i$; face $f$
  is the lower face of cell $f$. The owned cells are $i_s..i_u$.
\item Ideal gas with $R_d = 1$ in the derivation, so $T = p/\rho$; $R \equiv \rho/p$.
\item An overbar is a cell average; a subscript $f$ is a point value at a face.
\item $\bar q = q + \tfrac{\Delta z^2}{24} q'' + O(\Delta z^4)$ for a smooth $q$ (cell average about the centre).
\item $\mathcal I[\cdot]_f$: the face value the high-order (WENO5) reconstruction returns from cell averages of
  smooth data, to $O(\Delta z^5)$.
\end{itemize}

\section*{1. The base well-balanced x1 reconstruction}

The solver reconstructs perturbations about a hydrostatic reference and restores the reference at the faces
(\texttt{hydro\_forward.cpp}, step 2): $p' = \bar p - p_{\rm ref}$, $\rho' = \bar\rho - \rho_{\rm ref}$, even-parity
wall ghosts of $p'$ and $\rho'$, WENO5 of $p'$ and $\rho'$, then

\begin{equation*}
p^{L,R}_f = \widehat{p'}^{L,R}_f + p_{{\rm sf},f}, \qquad \rho^{L,R}_f = \widehat{\rho'}^{L,R}_f + \rho_{{\rm sf},f} .
\end{equation*}

The kernel (\texttt{hydro\_ref\_x1\_impl.h}) builds:

\begin{itemize}
\item \textbf{face pressure} by a top-down scan, $p_{{\rm sf},i-1/2} = p_{{\rm sf},i+1/2} + g\bar\rho_i\Delta z_i$: the
  discrete hydrostatic balance itself;
\item \textbf{cell pressure} $p_{\rm ref}$: on a uniform grid the cell average of the quintic through six face
  pressures, $(11, -93, 802, 802, -93, 11)/1440$, one-sided rows at clamped walls; on a non-uniform grid the
  log-mean $\Delta p / \ln(p_{\rm lo}/p_{\rm hi})$;
\item \textbf{cell density} $\rho_{{\rm ref},i} = p_{{\rm ref},i}\, r^s_i$, with $r_i = \bar\rho_i/\bar p_i$ smoothed by the
  binomial $B = (1, 4, 6, 4, 1)/16$ (edge replicated at a clamped wall);
\item \textbf{face density} $\rho_{{\rm sf},f} = p_{{\rm sf},f}\,\tfrac12(r^s_{f-1} + r^s_f)$.
\end{itemize}

\section*{2. The base face-density offset is $O(\Delta z^2)$}

Since the reconstruction treats $\rho'$ as cell averages, the face density it produces is

\begin{equation*}
\rho_f = \mathcal I[\bar\rho - \rho_{\rm ref}]_f + \rho_{{\rm sf},f} = \mathcal I[\bar\rho]_f + \delta\rho_f,
\qquad \delta\rho_f \equiv \rho_{{\rm sf},f} - \mathcal I[\rho_{\rm ref}]_f .
\end{equation*}

So $\rho_f$ is a consistent high-order face value exactly when $\rho_{\rm sf}$ is the face value of the cell
field $\rho_{\rm ref}$ itself, whatever the accuracy of $\rho_{\rm ref}$. Step by step, for smooth $p$, $\rho$, $R$:

\begin{itemize}
\item Ratio of averages: $r_i = \bar\rho_i/\bar p_i = R_i + \tfrac{\Delta z^2}{24}(\rho'' - R p'')/p + O(\Delta z^4)$.
\item Binomial bias: $B$ has unit sum and second moment $\sum_m m^2 w_m = 1$ (cells), so
  $B q = q + \tfrac{\Delta z^2}{2} q'' + O(\Delta z^4)$ and $r^s_i = r_i + \tfrac{\Delta z^2}{2}R''$.
\item Kernel cell density, with $p_{\rm ref} = \bar p + c + O(\Delta z^6)$ (section 6): $\rho_{{\rm ref},i} = \bar\rho_i +$
  \textbackslash\{\}tfrac\{\textbackslash\{\}Delta z\textasciicircum{}2\}\{2\} p R'' + O(\textbackslash\{\}Delta z\textasciicircum{}4)$, so $\textbackslash\{\}mathcal I[\textbackslash\{\}rho\_\{\textbackslash\{\}rm ref\}]\_f = \textbackslash\{\}rho\_f + \textbackslash\{\}tfrac\{\textbackslash\{\}Delta z\textasciicircum{}2\}\{2\} pR''$.$
\item Face reference: the mean of the two neighbouring cell values adds $\tfrac{\Delta z^2}{8}R''$, so
  $\rho_{{\rm sf},f} = p_f\big[R_f + \tfrac{\Delta z^2}{24}\tfrac{\rho'' - Rp''}{p} + \tfrac{\Delta z^2}{8}R'' + \tfrac{\Delta z^2}{2}R''\big]$.
\item Subtract, with $\rho'' - Rp'' = 2p'R' + pR''$:
\end{itemize}

\begin{equation*}
\delta\rho_f = \frac{\Delta z^2}{12}\big(p'R' + 2pR''\big) + O(\Delta z^4).
\end{equation*}

\texttt{wb\_ref4\_weights.py} (check 3) derives the same expression symbolically from exact cell averages of
quadratic $p$ and $R$ about the face. At a clamped wall, edge replication in $B$ is not exact even for linear
$r$, so the first two cells carry an $O(\Delta z)$ offset on top (a band of width $O(\Delta z)$).

\textbf{Where it enters.} The face pressure is untouched, so the offset enters only the x1 mass flux
$\bar u\rho_{L/R}$ at linear order, and through it the face gravity work ($-\tfrac g2(\delta F_{\rho,i-1/2} +$
\textbackslash\{\}delta F\_\{\textbackslash\{\}rho,i+1/2\})$ per cell). The energy flux $\textbackslash\{\}bar u(\textbackslash\{\}kappa p + \textbackslash\{\}rho K)$ is independent of the face$
density at linear order. The x2/x3 faces use the restored primitives, so this offset is separate from the
\#289 x2 covariance term and adds to it.

\section*{3. The fix: face density as the face value of the kernel's cell density}

The kernel's $\rho_{\rm ref}$ is kept. By section 2 only $\rho_{\rm sf}$ must change:

\begin{equation*}
\rho_{{\rm sf},f} = \mathcal I_4[\rho_{\rm ref}]_f \equiv P'(z_f),
\end{equation*}

where $P$ is the quartic through the primitive values $P(z_{s+j}) = \sum_{k<j}\rho_{{\rm ref},s+k}\Delta z_{s+k}$,
$j = 0..4$ (five faces enclosing four cells), window $s = f - 2$, kept inside the owned cells at a clamped
wall. The weight of cell $s+k$ is $\Delta z_{s+k}\sum_{j>k}L_j'(z_f)$ with $L_j$ the Lagrange basis on the five
faces; this uses physical spacing and is exact for cubic point profiles on any grid. On a uniform grid
(check 2):

\begin{itemize}
\item interior: $(-1, 7, 7, -1)/12$;
\item wall face, window starting at the wall: $(25, -23, 13, -3)/12$;
\item the next face: $(3, 13, -5, 1)/12$ (and their mirror images at the top).
\end{itemize}

Then $\delta\rho_f = \mathcal I_4[\rho_{\rm ref}]_f - \mathcal I[\rho_{\rm ref}]_f = O(\Delta z^4)$, and the face
density the solver uses is $\mathcal I[\bar\rho]_f + O(\Delta z^4)$.

\section*{4. Ordering}

The resolution flag (section 7) is built right after the kernel. The face part runs after the x1 seam
ghost-row exchange of $(p_{\rm ref}, \rho_{\rm ref})$, so a column split along x1 gets the same faces as one
block (\texttt{test\_x1\_seam\_split\_wb\_ref4}).

\section*{5. Non-uniform x1 grids: the cell pressure}

A keyed stretched x1 (\texttt{cells/x1rat} or \texttt{geometry/x1f}, \#280) already has a
sixth-order cell pressure: the cell average of the degree-5 interpolant through six faces, built from the
widths (\#280 (iv)). There the switch keeps it, so REF4 contributes only the face density of section 3,
and \texttt{balance\_column} does not run REF4: the stretched rest state is the
same with the switch on or off. On a keyed
stretched family the measured order of $N^2_{\rm eff}$ is 4.06/4.04 (1 e-fold) and 3.78/3.89 (3 e-folds) at
$h_{\max}/h_{\min} = 4$. On a Cartesian x1 \texttt{SNAP\_X1\_CENTROID\_EXACT} has no content of its own and runs as
\texttt{SNAP\_WB\_REF4}.

\section*{6. Exact discrete balance is kept}

At rest $p' = $ const, so $p_L = p_R = p_{\rm sf} + c$, $\bar u = 0$ and the LMARS face pressure is
$p_{\rm sf} + c$; the momentum-flux difference across cell $i$ is $g\bar\rho_i\Delta z_i$ and cancels the gravity
source exactly. The density reference is not part of this pairing: with $\bar u = 0$ the mass flux and the
face gravity work vanish whatever the face density is. The fix never changes $p_{\rm sf}$ or $p_{\rm ref}$, so
the discrete rest state $\bar p = p_{\rm ref} + c$ is the base's.

Why $p_{\rm ref} = \bar p + c + O(\Delta z^6)$ on a hydrostatic background: the scan gives
$p_{{\rm sf},i-1/2} - p_{{\rm sf},i+1/2} = g\bar\rho_i\Delta z_i = \int_{\rm cell} g\rho\,dz$ exactly, so the scan
faces are the exact face pressures up to one column constant $c$ (the top anchor); the six-face quadrature
then has error $O(\Delta z^6)$. The constant changes $\rho_{\rm ref}$ by the smooth $cR$, which section 3
carries consistently because the face value is taken of the same $\rho_{\rm ref}$.

\section*{7. Guards}

A guarded face keeps the kernel's value. None fires on a resolved smooth column.

\begin{itemize}
\item Range: $\mathcal I_4[\rho_{\rm ref}]_f$ outside $[\min, \max]$ of $\rho_{\rm ref}$ in its two neighbouring cells,
  with a relative margin $10^{-10}$, keeps the kernel's face value.
\item Resolution: a cell with $\lvert\ln(p_{{\rm sf},i-1/2}/p_{{\rm sf},i+1/2})\rvert > 0.5$ (fewer than two cells per
  pressure scale height) is flagged, the flag is dilated by two cells, and ghost cells past a clamped wall do
  not count. Faces next to a flagged cell keep the kernel's face value.
\item Seams: each block computes the flag from its own scan pressures, ghost cells included, and the flag is not
  exchanged. The flag of a cell or a seam face reads $p_{\rm sf}$ at most three cells away, so with nghost
  $\ge 3$ (checked at setup) the two sides of an x1 seam agree, except at an exact tie
  $\lvert\ln(p_{{\rm sf},i-1/2}/p_{{\rm sf},i+1/2})\rvert = 0.5$, where the two scans' last-ulp difference can
  put the cell on either side (\texttt{test\_x1\_seam\_split\_wb\_ref4}: the flag switching on next to a seam).
\item A block with a clamped wall and fewer than four owned cells keeps the kernel's reference. Its stencil cache
  is then "not usable" and holds no weights, so the check that rebuilds the cache for another device or dtype
  (\texttt{WbRef4Stencils::stale}) never reads them; before \#298 it read the device of the undefined weight tensor and
  the second RK stage threw (\texttt{tests/test\_stencil\_cache\_small\_block.py}: nx1 2–5 per block now run).
\end{itemize}

The threshold, the dilation and the margin are design choices, not derived.

\section*{8. The oracle}

Cartesian, one-step, linear. Neutral polytrope with $\gamma = 5/3$, $m = 1/(\gamma-1)$, $g = m+1$:
$T_0 = 1 + L_z - z$, $\rho_0 = T_0^m$, $p_0 = T_0^{m+1}$; the column is $n$ pressure e-folds deep,
$L_z = e^{n/(m+1)} - 1$; $L_x = 2L_z$, $n_x = 2n_z$; reflecting x1 walls, periodic x2, WENO5, LMARS, face
gravity work, the \#289 flux covariance on.

\begin{itemize}
\item Mode, seeded as momentum: $\rho_0 v_1 = Ak\sin(qz)\cos(kx)$, $\rho_0 v_2 = -Aq\cos(qz)\sin(kx)$,
  $q = \pi/L_z$, $k = 2\pi/L_x$, $A = 10^{-4}$.
\item Cell-average IC: exact cell averages (4x4 Gauss-Legendre) of $\rho$, $m_1$, $m_2$ and $E$; primitives
  $\bar\rho$, $\bar m/\bar\rho$, $\bar p = (\gamma-1)(\bar E - \lvert\bar m\rvert^2/2\bar\rho)$.
\item One RK3 step at $\Delta t = 0.3\Delta z/\sqrt{\gamma T_{\rm bottom}}$; with $s = \ln(p\rho^{-\gamma})$ from the
  end-of-step conserved state, $\delta s_i = [(s^1 - s^0)_{\rm mode} - (s^1 - s^0)_{\rm rest}]/\Delta t$.
\item $N^2_{\rm eff} = \tfrac g\gamma \sum_i(-\delta s_i)w_i / \sum_i w_i^2$, $w = v_1$ at $t = 0$, all interior cells.
  Reported as $N^2_{\rm eff}n_z^2$; the order is that of $\lvert N^2_{\rm eff}\rvert$ itself between doublings.
\end{itemize}

\textbf{No diagnostic floor.} $\nabla\cdot m = 0$ pointwise, so $\partial_t\bar\rho = 0$ exactly. The linear energy
tendency is $-\nabla\cdot(\kappa p_0 v) - g m_1 = -\kappa\, m\cdot\nabla T_0 - g m_1 = (\kappa - g)m_1 = 0$, since
$p_0v = T_0 m$, $T_0' = -1$ and $\kappa = \gamma/(\gamma-1) = g$. So the exact cell-average tendencies vanish at
linear order and every measured $\delta s$ is scheme error, at every depth.

\section*{10. Tests that pin the kernel's reference}

Both run unchanged with the switch off and a second time with it set (\texttt{*\_wb\_ref4} ctests):

\begin{itemize}
\item \texttt{test\_balance\_column}: the switch changes no cell pressure, so the balanced columns are the kernel's.
\item \texttt{test\_face\_floor}: the kernel's cell density does not follow the dipped cell, with or without the switch,
  so the floor fires on the same face and the fluxes there equal the switch-off values.
\end{itemize}
